Architecture & Storage Information

How SpendWise protects your financial privacy
  • 100% Client-Side Privacy: All transaction records and budgets reside exclusively in your browser's localStorage. No financial data is ever transmitted to any external server or cloud service.
  • Integer Paise Precision: Currency balances are calculated and stored internally in integer paise (1 Rupee = 100 paise) to eliminate standard floating-point arithmetic errors.
  • Static Vercel Deployment: Runs as a high-performance zero-dependency static web application requiring no backend runtime or database configuration.
  • Device Boundary: Because data is stored in the browser's local sandbox, data does not automatically synchronize across different devices or browsers unless exported and imported via JSON backup.
